# 인터내셔널 OJ

## 문제

인터내셔널 OJ에는 $N$개의 채점 서버가 있다. 채점 서버에는 $1, 2, \dots, N$번의 번호가 붙어 있다. 각 채점 서버는 하나의 채점 큐를 가지며, 한 번에 하나의 제출만 채점할 수 있다. 제출에는 제출된 문제의 번호, 제출자 닉네임, 채점에 필요한 시간이 포함된다. 인터내셔널 OJ를 사용하는 사람들은 매우 똑똑하기 때문에 모든 제출 결과는 `AC`이다.

제출은 다음 과정에 따라 처리된다. 제출이 특정 채점 서버의 큐에 삽입되면, 채점 서버는 큐에 먼저 삽입된 제출부터 순서대로 채점한다. 하나의 제출을 채점하는 동안에는 다른 제출을 채점할 수 없으며, 채점 서버가 비어 있다면 새로 삽입된 제출의 채점을 즉시 시작한다. 채점이 완료되는 즉시 결과가 데이터베이스에 반영되며, 데이터베이스 반영에 걸리는 시간은 $0$이라고 가정한다. 하나의 제출에 대한 채점이 완료되면, 큐에 다음 제출이 존재하는 경우 같은 시각에 바로 다음 제출의 채점을 시작한다.

인터내셔널 OJ에서는 두 종류의 랭킹을 제공한다.

먼저 각 문제에 대해 채점이 완료된 제출들은 채점 시간이 짧은 순서로 정렬되며, 채점 시간이 같다면 채점 완료 시각이 빠른 순서로, 채점 완료 시각도 같다면 제출 쿼리가 먼저 주어진 순서로 정렬된다. 한 사용자가 같은 문제를 여러 번 제출했더라도, 각각의 제출은 서로 다른 기록으로 취급한다.

또한 사용자가 푼 문제 수는 해당 사용자가 채점 완료된 `AC` 제출을 하나 이상 보유한 서로 다른 문제의 개수로 정의되며, 같은 문제를 여러 번 제출하더라도 푼 문제 수는 한 번만 증가한다. 사용자들은 푼 문제 수가 많은 순서로 정렬되며, 푼 문제 수가 같다면 현재의 푼 문제 수를 달성한 시각이 빠른 순서로, 해당 시각도 같다면 닉네임의 사전순으로 정렬된다. 여기서 현재의 푼 문제 수를 달성한 시각은 사용자가 가장 최근에 새로운 문제를 처음 푼 제출의 채점 완료 시각을 의미하며, 아직 채점이 완료된 제출이 하나도 없는 사용자는 사용자 랭킹에 포함되지 않는다.

인터내셔널 OJ의 개발자 `A`는 제출이 처리됨에 따라 랭킹이 어떻게 변하는지 확인하려고 한다. $Q$개의 쿼리를 순서대로 처리하고, 출력 쿼리에 대한 결과를 출력하자. 쿼리는 다음 세 종류 중 하나이다.

```text
1 t i x y s
```

시각 $t$에 $i$번 채점 서버의 채점 큐에 문제 번호 $x$, 채점 시간 $y$, 제출자 닉네임 $s$인 제출을 삽입한다. 채점 서버가 시각 $t$에 비어 있다면 제출의 채점을 즉시 시작한다.

```text
2 t x
```

시각 $t$까지 채점이 완료된 제출만을 이용하여 $x$번 문제의 랭킹을 출력한다. 랭킹이 높은 제출부터 최대 5개를 출력하며, 채점이 완료된 제출이 5개보다 적다면 존재하는 제출을 모두 출력한다. 각 제출은 `닉네임 채점시간` 형식으로 한 줄에 하나씩 출력하고, 채점이 완료된 제출이 하나도 없다면 `-1`을 출력한다.

```text
3 t
```

시각 $t$까지 데이터베이스에 반영된 결과를 기준으로 사용자 랭킹을 출력한다. 랭킹이 높은 사용자부터 최대 5명을 출력하며, 랭킹에 포함되는 사용자가 5명보다 적다면 존재하는 사용자를 모두 출력한다. 각 사용자는 `닉네임 푼문제수` 형식으로 한 줄에 하나씩 출력하고, 랭킹에 포함되는 사용자가 한 명도 없다면 `-1`을 출력한다.

## 입력

첫째 줄에 채점 서버의 수 $N$과 쿼리의 수 $Q$가 주어진다. 이후 $Q$개의 줄에 쿼리가 한 줄에 하나씩 주어진다.

## 출력

`2`번 또는 `3`번 쿼리가 주어질 때마다 해당 쿼리의 결과를 출력한다.

## 제한

- $1 \le N,Q \le 200,000$
- $0 \le t \le 10^9$
- 쿼리의 시각 $t$는 감소하지 않는 순서로 주어진다.
- $1 \le i \le N$
- $1 \le x \le 10^9$
- $1 \le y \le 10^9$
- 닉네임 $s$는 영문 소문자와 숫자로 이루어진 길이 $1$ 이상 $20$ 이하의 문자열이다.
- 서로 다른 사용자가 같은 닉네임을 사용하는 경우는 없다.
- 입력으로 주어지는 모든 수는 정수이다.

## 예제 입력

```text
2 10
1 0 1 1 5 alice
1 0 2 1 3 bob
2 2 1
2 3 1
1 3 2 2 2 alice
3 4
2 5 1
3 5
1 5 1 1 1 carol
2 6 1
```

## 예제 출력

```text
-1
bob 3
bob 1
bob 3
alice 5
alice 2
bob 1
carol 1
bob 3
alice 5
```

## 예제 설명

`bob`의 제출은 2번 서버에서 시각 $0$에 채점을 시작하여 시각 $3$에 완료된다. `alice`의 1번 문제 제출은 시각 $5$에 완료된다. `alice`의 2번 문제 제출도 시각 $5$에 완료되므로, 시각 $5$에 `alice`가 푼 문제 수는 2개가 된다. `carol`의 제출은 시각 $5$에 채점을 시작하여 시각 $6$에 완료된다. 시각 $6$의 1번 문제 랭킹은 채점 시간이 짧은 `carol`, `bob`, `alice` 순서이다.
