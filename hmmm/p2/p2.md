# 문제

A는 여러 개의 서브태스크로 이루어진 문제를 만들었다.

각 서브태스크 $i$에는 $A_i$점이 배정되어 있다. 하지만 모든 서브태스크가 독립적으로 채점되는 것은 아니다. 각 서브태스크에는 부모 서브태스크가 존재할 수 있으며, 모든 부모 서브태스크에서 점수를 획득해야만 해당 서브태스크가 채점된다.

구체적으로, $i$번 서브태스크의 부모가
$p_{i,1}, p_{i,2}, \dots, p_{i,k}$라 하자.

$p_{i,1}, p_{i,2}, \dots, p_{i,k}$번 서브태스크에서 **모두 점수를 획득한 경우에만** $i$번 서브태스크의 결과를 확인한다.

- $i$번 서브태스크의 결과가 `AC`라면 $A_i$점을 획득한다.
- 그 외의 결과라면 점수를 획득하지 못한다.

부모가 없는 서브태스크는 다른 서브태스크의 결과와 관계없이 바로 채점된다.

모든 서브태스크 $i$에 대해, $i$번 서브태스크의 부모가 존재한다면 그 번호는 항상 $i$보다 작다.

A는 문제를 공개한 뒤, 서브태스크의 부모 관계를 잘못 설정했다는 사실을 알게 되었다. A는 부모 관계를 올바르게 수정했지만, 이미 많은 제출이 쌓여 있었기 때문에 기존 제출들을 수정된 부모 관계를 기준으로 다시 채점해야 한다.

재채점한 결과를 다음과 같이 분류한다고 하자.

- 기존 점수보다 점수가 **낮아진** 제출을 **억까**
- 기존 점수보다 점수가 **높아진** 제출을 **나이스**

수정 전 부모 관계와 수정 후 부모 관계, 그리고 각 제출의 서브태스크별 결과가 주어질 때, 억까를 당한 제출의 수와 나이스한 제출의 수를 구하여라.

# 입력

첫째 줄에 서브태스크의 개수 $N$과 제출의 개수 $M$이 공백으로 구분되어 주어진다.

둘째 줄에 각 서브태스크의 배점 $A_1, A_2, \dots, A_N$이 공백으로 구분되어 주어진다.

다음 $N$개의 줄에는 수정 전 부모 관계가 주어진다.

$i$번째 줄에는 $i$번 서브태스크의 부모 서브태스크의 개수 $K_i$와, 이어서 $K_i$개의 부모 서브태스크 번호가 공백으로 구분되어 주어진다.

부모 서브태스크가 없는 경우 $K_i=0$이며, 해당 줄에는 `0`만 주어진다.

다음 $N$개의 줄에는 같은 형식으로 수정 후 부모 관계가 주어진다.

다음 $M$개의 줄에는 각 제출의 서브태스크별 결과
$S_1, S_2, \dots, S_N$이 공백으로 구분되어 주어진다.

각 $S_i$는 다음 중 하나이다.

`AC`, `WA`, `RE`, `TLE`, `MLE`, `CE`

$S_i$가 `AC`인 경우, $i$번 서브태스크가 실제로 채점된다면 $A_i$점을 획득한다. 그 외의 경우에는 해당 서브태스크가 채점되더라도 점수를 획득하지 못한다.

# 출력

억까를 당한 제출의 수와 나이스한 제출의 수를 공백으로 구분하여 출력한다.

# 제한

- $1 \le N \le 1\,000$
- $1 \le M \le 10\,000$
- $1 \le A_i \le 100$
- $S_i \in \{\text{AC}, \text{WA}, \text{RE}, \text{TLE}, \text{MLE}, \text{CE}\}$
- $i$번 서브태스크의 모든 부모 서브태스크 번호는 $i$보다 작으며 중복되지 않는다.
- 수정 전 부모 관계에서 부모-자식 관계의 총 개수는 $3\,000$ 이하이다.
- 수정 후 부모 관계에서 부모-자식 관계의 총 개수는 $3\,000$ 이하이다.
- $N$, $M$, $A_i$는 모두 정수이다.
