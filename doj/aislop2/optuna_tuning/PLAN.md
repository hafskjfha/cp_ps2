# Optuna 담금질 실험 도구 구현 계획

목표: 기존 고정 평가 환경을 사용하여 연산열 담금질법의 파라미터를 반복 탐색하고, 중단 후 재개하며, 검증된 단일 Python 제출 파일을 보존한다.

- `sa_solver.py`: 탐욕 초기해 + 연산열 담금질, 고정 난수 시드, 최선해 보존. 표준 라이브러리만 사용한다.
- `evaluation.py`: 기존 simulator/validator/benchmark/readiness를 재사용한다. 실제 제출 파일을 별도 프로세스에서 제한 시간 내 실행한다. stable320 전체와 재현 검증을 통과한 엄격한 개선만 폴더 내부 체크포인트로 저장한다.
- `tune.py`: Optuna TPE, SQLite 재개, 시험별 독립 시드, 중간 가지치기, 시험 기록, 파라미터/코드/벤치마크 지문 확인, 단일 실행 잠금, 주기적 stable 검증.
- `test_*.py`: 회전/상태 갱신 차등 검사, 유효성/제한 시간, 내보낸 파일 실행, 중단/재개와 실험 조건 변경 거부를 확인한다.
- `README.md`: Windows 실행 예제, 계속 실행/중단/재개, 학습 점수와 검증 점수 차이, 기존 최고해와의 관계를 설명한다.

검증 순서: 기존 평가 테스트 → 신규 테스트 → 실제 Optuna 짧은 탐색 및 재개 → 탐욕/기본 담금질/튜닝 후보 smoke 비교 → stable 검증 및 독립 코드 리뷰.

기존 `submissions`, `results/history.csv`, `solvers/current.py`, 고정 테스트케이스는 유지한다. 별도 실험의 최선과 저장소 전체 최선을 혼동하지 않는다. 장기 실행 코드를 제공하고 이번 작업에서는 유한한 검증 실행을 수행한다.
